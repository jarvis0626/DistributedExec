Worker computers

      
Connect another computer
  1. Install DistributedExec and Docker Desktop using Linux containers.
  2. Prepare the runtime in the desktop launcher.
  3. Choose Join as a worker and enter the host address and pairing code.
On different Wi-Fi networks, choose Different networks in the desktop launcher, finish connection setup on both computers, then copy/paste the host's connection invitation.
Pairing codes are shown in the host's desktop launcher. Host-only mode needs no Docker. Plain HTTP is for a trusted private LAN and does not encrypt scripts or credentials.
